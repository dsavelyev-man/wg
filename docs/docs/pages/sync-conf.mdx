# syncConf

Apply configuration changes to a running WireGuard interface without restarting it.

## How it works

`syncConf(iface)`:

1. Runs `wg-quick strip <iface>`.
2. Writes the stripped configuration to a temporary file with mode `0600`.
3. Runs `wg syncconf <iface> <temporary-file>`.
4. Removes the temporary file.

The interface must already be running, and the process generally needs root privileges.

## Basic usage

```ts
import { syncConf } from "@kriper0nind/wg-utils"

await syncConf("wg0")
```

## Automatic sync after config changes

Peer helpers accept `SyncOptions`:

```ts
type SyncOptions = {
  iface?: string
  sync?: boolean | "auto"
}
```

```ts
import { addPeer, deletePeer, updatePeer } from "@kriper0nind/wg-utils"

await addPeer("/etc/wireguard/wg0.conf", {
  publicKey: clientPublicKey,
  sync: "auto",
})

await updatePeer(
  "/etc/wireguard/wg0.conf",
  clientPublicKey,
  { PersistentKeepalive: 30 },
  { sync: true },
)

await deletePeer("/etc/wireguard/wg0.conf", { publicKey: clientPublicKey }, { sync: false })
```

Behavior:

- `sync: "auto"` or omitted: sync only if `isWgUp(iface)` succeeds.
- `sync: true`: always call `syncConf()`.
- `sync: false`: update only the file.
- `iface`: overrides the name derived from the file name.

`readConfig()` and `writeConfig()` never sync automatically:

```ts
import { readConfig, syncConf, writeConfig } from "@kriper0nind/wg-utils"

const config = await readConfig("/etc/wireguard/wg0.conf")
config.Interface!.ListenPort = 51821
await writeConfig("/etc/wireguard/wg0.conf", config)
await syncConf("wg0")
```

## Sync or restart?

Use `syncConf()` for changes supported by `wg syncconf`, including peers, endpoints, allowed IPs, and keepalives.

Restart the interface when changing settings that require re-running `wg-quick`, such as interface addresses, routes, DNS, MTU, or `PostUp`/`PostDown` behavior.

## Error handling

```ts
import { CommandError, syncConf } from "@kriper0nind/wg-utils"

try {
  await syncConf("wg0")
} catch (error) {
  if (error instanceof CommandError) {
    console.error(error.command, error.args, error.stderr)
  }
}
```
