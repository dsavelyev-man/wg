# checkWg & requireWg

Check whether the WireGuard CLI is available.

## checkWg

```ts
checkWg(): Promise<boolean>
```

Returns `true` when `wg --version` succeeds and `false` when it fails.

```ts
import { checkWg } from "@kriper0nind/wg-utils"

if (await checkWg()) {
  console.log("WireGuard tools are available")
}
```

Set `WG_UTILS_WG_PATH` to test an executable outside `PATH`.

## requireWg

```ts
requireWg(): Promise<void>
```

Calls `checkWg()` and throws when WireGuard is unavailable.

```ts
import { requireWg } from "@kriper0nind/wg-utils"

await requireWg()
```

The error message is:

```text
WireGuard is not installed or not available in PATH. Install WireGuard tools or set WG_UTILS_WG_PATH.
```

## Pre-flight example

```ts
import { addPeer, generateKeys, installWg, requireWg } from "@kriper0nind/wg-utils"

try {
  await requireWg()
} catch {
  await installWg()
}

const clientKeys = await generateKeys()
await addPeer("/etc/wireguard/wg0.conf", {
  publicKey: clientKeys.publicKey,
})
```
