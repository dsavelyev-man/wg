# parse & stringify

Convert between WireGuard configuration text and typed JavaScript objects.

## parse

```ts
import { parse } from "@kriper0nind/wg-utils"

const config = parse(`
[Interface]
PrivateKey = server-private-key
Address = 10.0.0.1/24
Address = fd00::1/64
ListenPort = 51820

[Peer]
PublicKey = client-public-key
AllowedIPs = 10.0.0.2/32
`)
```

The result uses the exported types:

```ts
import type { WireGuardConfig, WireGuardInterface, WireGuardPeer } from "@kriper0nind/wg-utils"

const config: WireGuardConfig = {
  Interface: {
    PrivateKey: "server-private-key",
    Address: ["10.0.0.1/24", "fd00::1/64"],
    ListenPort: 51820,
  },
  Peers: [
    {
      PublicKey: "client-public-key",
      AllowedIPs: "10.0.0.2/32",
    },
  ],
}
```

### Parsing behavior

- Section names are normalized for `[Interface]` and `[Peer]`.
- Unknown sections are preserved using their original names.
- Blank lines and comment lines starting with `#` or `;` are ignored.
- Repeated keys inside a section are merged as comma-separated values.
- Invalid section headers, values before a section, missing keys, and empty values throw `ConfigParseError`.
- Comments are not preserved in the parsed object.

## stringify

```ts
import { stringify } from "@kriper0nind/wg-utils"

const text = stringify({
  Interface: {
    Address: ["10.0.0.1/24", "fd00::1/64"],
    ListenPort: 51820,
    PrivateKey: "server-private-key",
  },
  Peers: [
    {
      PublicKey: "client-public-key",
      AllowedIPs: "10.0.0.2/32",
    },
  ],
})
```

Output:

```ini
[Interface]
Address = 10.0.0.1/24, fd00::1/64
ListenPort = 51820
PrivateKey = server-private-key

[Peer]
PublicKey = client-public-key
AllowedIPs = 10.0.0.2/32
```

### Serialization behavior

- `undefined`, `null`, empty strings, and empty arrays are omitted.
- Arrays are serialized as comma-separated values.
- `Interface` is written first, followed by each peer.
- Unknown object sections are appended after peers.
- Invalid configuration shapes throw `ConfigValidationError`.

## Round trip

```ts
import { parse, stringify } from "@kriper0nind/wg-utils"

const original = `[Interface]\nAddress = 10.0.0.1/24\n`
const normalized = stringify(parse(original))
```

Use `readConfig()` and `writeConfig()` when working with files. `writeConfig()` adds validation, atomic replacement, directory creation, backups, and safe file permissions.
