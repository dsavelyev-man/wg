# getInstallInstructions

Return platform-specific WireGuard installation instructions without installing anything.

## Signature

```ts
getInstallInstructions(): Promise<{
  platform: string
  packageManager?: string
  command?: string
  commands: string[][]
  name?: string
  supported: boolean
}>
```

## Example

```ts
import { getInstallInstructions } from "@kriper0nind/wg-utils"

const instructions = await getInstallInstructions()

if (instructions.supported) {
  console.log(instructions.command)
} else {
  console.log(`Automatic installation is not supported on ${instructions.platform}`)
}
```

## Response

- `platform`: value from `os.platform()`
- `packageManager`: detected package manager
- `command`: commands joined with `&&` for display
- `commands`: exact argument arrays that would be executed
- `name`: human-readable platform or distribution name
- `supported`: whether a supported installation plan was found

`commands` is the safer source for automation because it preserves executable and argument boundaries.

```ts
for (const command of instructions.commands) {
  const [file, ...args] = command
  console.log(file, args)
}
```

## Example response

```ts
{
  platform: "linux",
  packageManager: "apt-get",
  command: "sudo apt-get update && sudo apt-get install -y wireguard",
  commands: [
    ["sudo", "apt-get", "update"],
    ["sudo", "apt-get", "install", "-y", "wireguard"]
  ],
  name: "Ubuntu/Debian",
  supported: true
}
```

## Notes

- This function has no installation side effects.
- Detection depends on `/etc/os-release` on Linux and available package managers in `PATH`.
- Unsupported platforms return `supported: false` and an empty `commands` array.
