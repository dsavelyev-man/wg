# deletePeer

Remove peers or toggle their enabled state while preserving the rest of the configuration file.

## Delete

```ts
deletePeer(
  filepath: string,
  where: { publicKey: string },
  options?: ConfigWriteOptions & SyncOptions,
): Promise<boolean>
```

```ts
import { deletePeer } from "@kriper0nind/wg-utils"

const removed = await deletePeer("/etc/wireguard/wg0.conf", {
  publicKey: clientPublicKey,
})

if (removed) {
  console.log("Peer removed")
}
```

`deletePeer()` delegates to `removePeer()` and returns:

- `true` when an active or disabled peer block was removed
- `false` when no matching peer exists

Removal is idempotent, so deleting the same peer twice does not throw.

## Low-level removal

```ts
import { removePeer } from "@kriper0nind/wg-utils"

const removed = await removePeer("/etc/wireguard/wg0.conf", clientPublicKey, {
  backup: true,
  sync: "auto",
})
```

## Enable and disable

```ts
import { setPeerEnabled } from "@kriper0nind/wg-utils"

await setPeerEnabled("/etc/wireguard/wg0.conf", clientPublicKey, false)
await setPeerEnabled("/etc/wireguard/wg0.conf", clientPublicKey, true)
```

Disabling prefixes each line of the peer block with `#wg-utils: `. The block remains in the file and can be restored losslessly.

`setPeerEnabled()` returns `true` when the state changed and `false` when the peer was already in the requested state. A missing peer throws `PeerNotFoundError`.

## List disabled peers

```ts
import { listDisabledPeers } from "@kriper0nind/wg-utils"

const disabled = await listDisabledPeers("/etc/wireguard/wg0.conf")
```

`listPeers()` returns active peers only. `getPeer()` also searches active peers only.

## Options

All mutating peer helpers accept:

```ts
type ConfigWriteOptions = {
  createDirectory?: boolean
  backup?: boolean
  mode?: number
}

type SyncOptions = {
  iface?: string
  sync?: boolean | "auto"
}
```

- Writes are atomic and use `0600` by default.
- `backup: true` creates `<filepath>.bak-<timestamp>`.
- Omitted `sync` behaves like `"auto"` and syncs only a running interface.
- `sync: true` forces `wg syncconf`.
- `sync: false` only updates the file.

## Example

```ts
import { deletePeer, listDisabledPeers, listPeers, setPeerEnabled } from "@kriper0nind/wg-utils"

const configPath = "/etc/wireguard/wg0.conf"

// Temporarily suspend a peer
await setPeerEnabled(configPath, clientPublicKey, false)

// Inspect suspended peers
console.log(await listDisabledPeers(configPath))

// Restore access
await setPeerEnabled(configPath, clientPublicKey, true)

// Permanently remove the peer
await deletePeer(configPath, { publicKey: clientPublicKey })
```
