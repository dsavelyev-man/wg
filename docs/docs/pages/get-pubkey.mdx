# getPubKey & getPublicKey

Derive a WireGuard public key from a private key.

## getPubKey

Reads `Interface.PrivateKey` from a configuration file and returns the matching public key.

```ts
getPubKey(filepath: string): Promise<{
  publicKey: string
}>
```

```ts
import { getPubKey } from "@kriper0nind/wg-utils"

const { publicKey } = await getPubKey("/etc/wireguard/wg0.conf")
```

The private key is sent to `wg pubkey` through stdin and is never interpolated into a shell command.

## getPublicKey

Derives a public key directly from a private key string.

```ts
getPublicKey(privateKey: string): Promise<string>
```

```ts
import { getPublicKey } from "@kriper0nind/wg-utils"

const publicKey = await getPublicKey(privateKey)
```

## Complete server/client example

```ts
import {
  addPeer,
  generateClientConfig,
  generateKeys,
  getPubKey,
  initConf,
} from "@kriper0nind/wg-utils"

const serverKeys = await generateKeys()

await initConf("/etc/wireguard/wg0.conf", {
  privateKey: serverKeys.privateKey,
  ip: "10.0.0.1",
})

const { publicKey: serverPublicKey } = await getPubKey("/etc/wireguard/wg0.conf")

const clientKeys = await generateKeys()
const peer = await addPeer("/etc/wireguard/wg0.conf", {
  publicKey: clientKeys.publicKey,
})

const clientConfig = generateClientConfig({
  privateKey: clientKeys.privateKey,
  clientAddress: peer.address,
  serverPublicKey,
  serverEndpoint: "vpn.example.com:51820",
})
```

## Key validation

```ts
import { assertWireGuardKey, isWireGuardKey } from "@kriper0nind/wg-utils"

isWireGuardKey(value) // boolean
assertWireGuardKey(value, "private key") // returns trimmed key or throws
```

`isWireGuardKey()` and `assertWireGuardKey()` validate the base64 key shape. They do not verify that a private key is usable; `getPublicKey()` performs that derivation through `wg`.

## Errors

- `ConfigParseError` for malformed config text
- `ConfigValidationError` when `Interface.PrivateKey` is missing or invalid
- `WgNotFoundError` when `wg` is unavailable
- `CommandError` when `wg pubkey` fails
