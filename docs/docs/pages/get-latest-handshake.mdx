# getLatestHandshake

Read peer handshake and transfer statistics from a running WireGuard interface.

## Signature

```ts
getLatestHandshake(iface: string): Promise<HandshakeInfo[]>
```

```ts
interface HandshakeInfo {
  publicKey: string
  handshake?: string
  endpoint?: string
  allowedIps?: string
  latestHandshake?: string
  transfer?: string
  latestHandshakeSeconds: number
  transferRx: number
  transferTx: number
  persistentKeepalive: number
}
```

## Basic usage

```ts
import { getLatestHandshake } from "@kriper0nind/wg-utils"

const peers = await getLatestHandshake("wg0")

for (const peer of peers) {
  console.log({
    publicKey: peer.publicKey,
    handshake: peer.latestHandshake,
    endpoint: peer.endpoint,
    received: peer.transferRx,
    sent: peer.transferTx,
  })
}
```

## Fields

- `publicKey`: peer public key
- `handshake`: ISO timestamp or `undefined` when no handshake has completed
- `latestHandshake`: alias of `handshake`
- `latestHandshakeSeconds`: Unix timestamp in seconds, or `0`
- `endpoint`: current endpoint when known
- `allowedIps`: comma-separated `AllowedIPs`
- `transfer`: formatted summary such as `"1.20 MiB received, 300 KiB sent"`
- `transferRx`: received bytes
- `transferTx`: sent bytes
- `persistentKeepalive`: keepalive interval in seconds, or `0`

The function is built on `getInterfaceStatus()`, which parses the stable `wg show <iface> dump` format.

## Find stale peers

```ts
import { getLatestHandshake } from "@kriper0nind/wg-utils"

const peers = await getLatestHandshake("wg0")
const cutoff = Math.floor(Date.now() / 1000) - 5 * 60

const stale = peers.filter(
  (peer) => peer.latestHandshakeSeconds === 0 || peer.latestHandshakeSeconds < cutoff,
)

console.log(stale.map((peer) => peer.publicKey))
```

## Errors

- `ConfigValidationError` for an invalid interface name or invalid `wg` output
- `WgNotFoundError` when `wg` is unavailable
- `CommandError` when the interface does not exist or `wg show` fails
