# installWg

Detect the current platform and install WireGuard tools.

## Signature

```ts
installWg(options?: {
  force?: boolean
  silent?: boolean
}): Promise<void>
```

## Options

- `force?: boolean`: install even when `wg --version` already succeeds
- `silent?: boolean`: suppress informational output

## Supported detection

- Debian/Ubuntu family with `apt-get`
- Fedora/RHEL/CentOS/Rocky/AlmaLinux with `dnf`
- CentOS/RHEL with `yum`
- Arch Linux with `pacman`
- Alpine Linux with `apk`
- macOS with Homebrew
- Windows with Chocolatey
- Windows with Winget

The matching package manager must be available in `PATH`.

## Usage

```ts
import { installWg } from "@kriper0nind/wg-utils"

await installWg()
```

Force installation:

```ts
await installWg({ force: true })
```

Silent mode for automation:

```ts
await installWg({ silent: true })
```

## Behavior

1. Unless `force` is true, run `wg --version`.
2. Detect the platform and available package manager.
3. Run the installation commands without shell chaining.
4. Verify the result with `wg --version`.

On Unix systems, the function prefixes commands with `sudo` when the current process is not root. Ensure non-interactive sudo access when running unattended.

## Errors

- `UnsupportedPlatformError` when no supported package manager is detected
- `CommandError` when installation or verification fails
- Permission errors when sudo or elevated access is unavailable
