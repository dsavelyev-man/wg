# initConf

Create an initial WireGuard server configuration with optional NAT hooks.

## Signature

```ts
initConf(
  filepath: string,
  options: {
    privateKey: string
    port?: number
    ip?: string | string[]
    address?: string | string[]
    interface?: string
    dns?: string | string[]
    postUp?: string[]
    postDown?: string[]
    mtu?: string | number
    table?: string
    peers?: WireGuardPeer[]
  },
): Promise<void>
```

## Basic usage

```ts
import { generateKeys, initConf } from "@kriper0nind/wg-utils"

const serverKeys = await generateKeys()

await initConf("/etc/wireguard/wg0.conf", {
  privateKey: serverKeys.privateKey,
})
```

Defaults:

- `address`/`ip`: `10.0.0.1/24`
- `port`: `51820`
- outbound NAT interface: `eth0`
- `PostUp`/`PostDown`: iptables forward and NAT rules

## Custom settings

```ts
await initConf("/etc/wireguard/wg0.conf", {
  privateKey: serverKeys.privateKey,
  address: ["10.10.0.1/24", "fd00::1/64"],
  port: 51821,
  interface: "ens3",
  dns: ["1.1.1.1", "8.8.8.8"],
  mtu: 1380,
  table: "auto",
})
```

`address` takes precedence over `ip`. A bare address receives a `/24` prefix automatically.

## Custom hooks

```ts
await initConf("/etc/wireguard/wg0.conf", {
  privateKey: serverKeys.privateKey,
  postUp: [
    "iptables -A INPUT -i %i -p udp --dport 51820 -j ACCEPT",
    "iptables -A FORWARD -i %i -j ACCEPT",
  ],
  postDown: [
    "iptables -D INPUT -i %i -p udp --dport 51820 -j ACCEPT",
    "iptables -D FORWARD -i %i -j ACCEPT",
  ],
})
```

Arrays are joined with `; ` into a single `PostUp` or `PostDown` value.

Passing an empty `postUp` or `postDown` array omits that directive entirely, including the default NAT rules.

## Add initial peers

```ts
await initConf("/etc/wireguard/wg0.conf", {
  privateKey: serverKeys.privateKey,
  peers: [
    {
      PublicKey: clientPublicKey,
      AllowedIPs: "10.0.0.2/32",
    },
  ],
})
```

## Generated file

```ini
[Interface]
Address = 10.0.0.1/24
ListenPort = 51820
PrivateKey = server-private-key
PostUp = iptables -A FORWARD -i %i -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i %i -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE
```

The file is written through `writeConfig()` with mode `0600`.

## Security

- The required private key is written to the config file.
- Protect the file and the process environment handling the key.
- Review default firewall rules before using them in production.
- Enable IP forwarding separately according to your operating system.
