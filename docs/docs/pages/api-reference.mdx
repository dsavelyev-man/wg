# API Reference

All functions and types are exported from `@kriper0nind/wg-utils`.

## Types

```ts
type WireGuardScalar = string | number | boolean
type WireGuardValue = WireGuardScalar | string[] | null | undefined

interface WireGuardSection {
  [key: string]: WireGuardValue
}

interface WireGuardInterface extends WireGuardSection {
  Address?: string | string[]
  ListenPort?: string | number
  PrivateKey?: string
  DNS?: string | string[]
  MTU?: string | number
  Table?: string
  PostUp?: string
  PostDown?: string
}

interface WireGuardPeer extends WireGuardSection {
  PublicKey?: string
  PresharedKey?: string
  AllowedIPs?: string | string[]
  Endpoint?: string
  PersistentKeepalive?: string | number
  AllowedApps?: string
}

interface WireGuardConfig {
  Interface?: WireGuardInterface
  Peers?: WireGuardPeer[]
  [section: string]: WireGuardSection | WireGuardPeer[] | undefined
}

type IpAddressFamily = "ipv4" | "ipv6"

interface PeerAddressAllocation {
  address: string
  ip: string
  cidr: string
  family: IpAddressFamily
}

interface ConfigWriteOptions {
  createDirectory?: boolean
  backup?: boolean
  mode?: number
}

interface SyncOptions {
  iface?: string
  sync?: boolean | "auto"
}
```

## Configuration

### `parse(text)`

Parses WireGuard text into a typed object. Blank lines and comments are skipped. Repeated keys are merged as comma-separated values. Invalid input throws `ConfigParseError`.

```ts
const config = parse(configText)
```

### `stringify(config)`

Serializes a `WireGuardConfig`. `undefined`, `null`, empty strings, and empty arrays are omitted. Arrays are written as comma-separated values.

```ts
const text = stringify(config)
```

### `readConfig(filepath)`

Reads and parses a configuration file.

### `writeConfig(filepath, config, options?)`

Validates, serializes, and atomically writes a configuration file. Returns the generated text.

```ts
await writeConfig("/etc/wireguard/wg0.conf", config, {
  backup: true,
  createDirectory: true,
  mode: 0o600,
})
```

`writeConfig()` does not sync a running interface.

### `validateWireGuardConfig(config)`

Validates interface CIDRs, listening ports, peer public keys, duplicate peers, `AllowedIPs`, endpoint structure, and persistent keepalive values.

### `getInterfaceName(filepath)`

Returns the file name without a trailing `.conf`.

## Peer API

### `addPeer(filepath, options)`

Adds a peer, writes the file atomically, and optionally syncs a running interface.

```ts
const result = await addPeer("/etc/wireguard/wg0.conf", {
  publicKey,
  persistentKeepalive: 25,
  sync: "auto",
})
```

Options:

- `publicKey: string` required
- `presharedKey?: string`
- `persistentKeepalive?: number`
- `allowedIPs?: string | string[]`
- `endpoint?: string`
- `allowedApps?: string`
- `family?: "ipv4" | "ipv6"`
- `addressPool?: string`
- `iface?: string`
- `sync?: boolean | "auto"`

Returns:

```ts
{
  ip: string
  address: string
  family: "ipv4" | "ipv6"
  peer: WireGuardPeer
}
```

Without `allowedIPs`, the address is allocated from the matching `Interface.Address` subnet. With `allowedIPs`, the first CIDR determines the returned address metadata.

### `deletePeer(filepath, { publicKey }, options?)`

Removes an active or disabled peer. Returns `true` when removed and `false` when no match exists.

### `removePeer(filepath, publicKey, options?)`

Low-level idempotent removal used by `deletePeer()`.

### `getPeer(filepath, publicKey)`

Returns an active peer or `undefined`. Disabled peers are not returned.

### `listPeers(filepath)`

Returns active peers.

### `listDisabledPeers(filepath)`

Returns peers disabled with `setPeerEnabled()`.

### `updatePeer(filepath, publicKey, changes, options?)`

Updates selected fields in the original peer block and preserves unrelated file content.

```ts
await updatePeer("/etc/wireguard/wg0.conf", publicKey, {
  PersistentKeepalive: 30,
  Endpoint: null,
})
```

Use `null`, `undefined`, or `""` to remove a field.

### `setPeerEnabled(filepath, publicKey, enabled, options?)`

Comments or uncomments an entire peer block using the `#wg-utils: ` prefix. Returns whether the state changed.

### `appendPeer(filepath, peer, options?)`

Appends a peer block without parsing and rewriting the entire file.

### `addPeerToConfig(config, peer)`

Adds a peer to an in-memory configuration object. Throws `PeerAlreadyExistsError` for a duplicate public key.

## IP Utilities

### `getNextPeerAddress(config, options?)`

Allocates the first free IPv4 `/32` or IPv6 `/128` peer address.

```ts
const allocation = getNextPeerAddress(config, {
  family: "ipv6",
  addressPool: "fd00::/64",
})
```

Options:

- `family?: "ipv4" | "ipv6"`
- `addressPool?: string`

Other exports:

- `parseIpv4()`, `formatIpv4()`
- `parseIpv6()`, `formatIpv6()`
- `parseCidr()`, `formatAddress()`
- `isValidIp()`, `isValidCidr()`

## Key API

### `generateKeys(options?)`

Generates a key pair in memory. Optional `privateKeyPath` and `publicKeyPath` write files with mode `0600`.

```ts
const { privateKey, publicKey } = await generateKeys()
```

### `generatePresharedKey(options?)`

Generates a preshared key in memory. Optional `keyPath` writes it with mode `0600`.

### `getPubKey(filepath)`

Reads `Interface.PrivateKey` and derives the matching public key.

### `getPublicKey(privateKey)`

Derives a public key directly from a private key string.

### `isWireGuardKey(value)` / `assertWireGuardKey(value, label?)`

Validate the 32-byte base64 WireGuard key format.

## Server Configuration

### `initConf(filepath, options)`

Creates and atomically writes an initial server configuration.

```ts
await initConf("/etc/wireguard/wg0.conf", {
  privateKey,
  address: ["10.0.0.1/24", "fd00::1/64"],
  port: 51820,
  interface: "eth0",
  dns: ["1.1.1.1", "8.8.8.8"],
})
```

Options:

- `privateKey: string` required
- `port?: number`
- `ip?: string | string[]`
- `address?: string | string[]`
- `interface?: string`
- `dns?: string | string[]`
- `postUp?: string[]`
- `postDown?: string[]`
- `mtu?: string | number`
- `table?: string`
- `peers?: WireGuardPeer[]`

Defaults include `10.0.0.1/24`, port `51820`, and iptables NAT rules using `eth0`.

## Client API

### `generateClientConfig(options)`

Creates a standalone client configuration string.

Required fields: `privateKey`, `clientAddress`, `serverPublicKey`, `serverEndpoint`.

Optional fields include `allowedIPs`, `dns`, `persistentKeepalive`, `presharedKey`, `mtu`, `extraInterface`, and `extraPeer`.

### `generateClientQRCode(config, options?)`

Accepts configuration text, a `WireGuardConfig`, or `GenerateClientConfigOptions`.

Options:

- `outputPath?: string` writes a PNG and returns its path
- `type?: "data-url" | "terminal"` defaults to a PNG data URL
- `width?: number` defaults to `512`

## Interface API

### `up(iface, options?)` / `down(iface)`

Start or stop an interface without shell interpolation. Windows uses the WireGuard tunnel service.

### `restart(iface, options?)`

Stops and starts an interface.

### `isWgUp(iface)`

Returns whether `wg show <iface>` succeeds.

### `getInterfaceStatus(iface)`

Parses `wg show <iface> dump` into interface and peer statistics.

### `getLatestHandshake(iface)`

Returns peer handshake timestamps, endpoints, transfer counters, formatted transfer text, and keepalive values.

### `syncConf(iface)`

Runs `wg-quick strip`, writes a secure temporary file, and applies it with `wg syncconf`.

### `saveConfig(iface, options?)`

Saves a running configuration with `wg-quick save` or returns/writes `wg showconf` output.

### `validateInterfaceName(iface)` / `parseWgDump(iface, output)`

Validate an interface name or parse captured `wg dump` output.

## Installation and Checks

### `checkWg()` / `requireWg()`

Check for the `wg` executable or throw a descriptive error.

### `installWg(options?)`

Detects the platform and package manager, then installs WireGuard using argument-array commands.

Options:

- `force?: boolean`
- `silent?: boolean`

### `getInstallInstructions()`

Returns `{ platform, packageManager?, command?, commands, name?, supported }` without installing anything.

## Errors

All library errors extend `WireGuardError`:

- `ConfigParseError`
- `ConfigValidationError`
- `WgNotFoundError`
- `CommandError`
- `PeerNotFoundError`
- `PeerAlreadyExistsError`
- `AddressPoolExhaustedError`
- `UnsupportedPlatformError`

`CommandError` exposes `command`, `args`, `exitCode`, and `stderr`.
