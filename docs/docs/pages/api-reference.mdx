# API Reference

All functions and types are exported from `@kriper0nind/wg-utils`.

## Types

```ts
type WireGuardScalar = string | number | boolean
type WireGuardValue = WireGuardScalar | string[] | null | undefined

interface WireGuardInterface {
  Address?: string | string[]
  ListenPort?: string | number
  PrivateKey?: string
  DNS?: string | string[]
  MTU?: string | number
  Table?: string
  PostUp?: string
  PostDown?: string
  [key: string]: WireGuardValue
}

interface WireGuardPeer {
  PublicKey?: string
  PresharedKey?: string
  AllowedIPs?: string | string[]
  Endpoint?: string
  PersistentKeepalive?: string | number
  AllowedApps?: string
  [key: string]: WireGuardValue
}

interface WireGuardConfig {
  Interface?: WireGuardInterface
  Peers?: WireGuardPeer[]
  [section: string]: WireGuardSection | WireGuardPeer[] | undefined
}
```

## Configuration

### `parse(text)`

Parses WireGuard text into a typed configuration object. Comments and blank lines are ignored. Repeated keys are merged with commas. Invalid lines throw `ConfigParseError`.

```ts
const config = parse(`
[Interface]
PrivateKey = server-private-key
Address = 10.0.0.1/24
`)
```

### `stringify(config)`

Serializes a configuration. Undefined, null, and empty values are omitted. Arrays become comma-separated values.

```ts
const text = stringify({
  Interface: {
    PrivateKey: "server-private-key",
    Address: ["10.0.0.1/24", "fd00::1/64"],
  },
})
```

### `readConfig(filepath)` / `writeConfig(filepath, config, options?)`

Read and write typed config files. Writes are atomic and use mode `0600`.

```ts
const config = await readConfig("/etc/wireguard/wg0.conf")
config.Interface!.ListenPort = 51821
await writeConfig("/etc/wireguard/wg0.conf", config, { backup: true })
```

Write options:

- `createDirectory?: boolean`
- `backup?: boolean`
- `mode?: number`

### `validateWireGuardConfig(config)`

Validates addresses, ports, peer keys, duplicate peers, `AllowedIPs`, endpoints, and keepalive values.

## Peer API

### `addPeer(filepath, options)`

Adds a peer, allocates an address from the interface subnet, writes atomically, and optionally syncs the running interface.

```ts
const result = await addPeer("/etc/wireguard/wg0.conf", {
  publicKey: "peer-public-key",
  persistentKeepalive: 25,
  sync: "auto",
})
```

Options include:

- `publicKey`
- `allowedIPs`
- `presharedKey`
- `persistentKeepalive`
- `endpoint`
- `allowedApps`
- `family: "ipv4" | "ipv6"`
- `addressPool`
- `iface`
- `sync: boolean | "auto"`

Returns `{ ip, address, family, peer }`.

### `deletePeer(filepath, { publicKey }, options?)`

Removes an active or disabled peer. Returns `true` when removed and `false` when it did not exist.

### `getPeer(filepath, publicKey)`

Returns a peer or `undefined`.

### `listPeers(filepath)` / `listDisabledPeers(filepath)`

Lists active or disabled peers.

### `updatePeer(filepath, publicKey, changes, options?)`

Updates selected peer fields while preserving the rest of the config text.

```ts
await updatePeer("/etc/wireguard/wg0.conf", "peer-public-key", {
  PersistentKeepalive: 25,
})
```

### `setPeerEnabled(filepath, publicKey, enabled, options?)`

Disables a peer by commenting its complete block with a recognizable prefix and re-enables it losslessly.

### `removePeer(filepath, publicKey, options?)`

Low-level idempotent peer removal backing `deletePeer`.

## IP Utilities

### `getNextPeerAddress(config, options?)`

Allocates the first free IPv4 `/32` or IPv6 `/128` peer address from `Interface.Address`.

```ts
const allocation = getNextPeerAddress(config, { family: "ipv6" })
```

Options:

- `family?: "ipv4" | "ipv6"`
- `addressPool?: string`

### Other exports

- `parseIpv4`, `formatIpv4`
- `parseIpv6`, `formatIpv6`
- `parseCidr`, `formatAddress`
- `isValidIp`, `isValidCidr`

## Key API

### `generateKeys(options?)`

Generates a key pair in memory. Optional paths write keys with mode `0600`.

```ts
const { privateKey, publicKey } = await generateKeys()
```

### `generatePresharedKey(options?)`

Generates a preshared key in memory and optionally writes it to `keyPath`.

### `getPubKey(filepath)`

Reads `Interface.PrivateKey` and derives the public key.

### `getPublicKey(privateKey)`

Derives a public key directly from a private key string.

### `isWireGuardKey(value)` / `assertWireGuardKey(value, label?)`

Validates the 32-byte base64 WireGuard key format.

## Server Configuration

### `initConf(filepath, options)`

Creates an initial server config. Optional values are omitted rather than serialized as `undefined`.

```ts
await initConf("/etc/wireguard/wg0.conf", {
  privateKey: serverPrivateKey,
  ip: "10.0.0.1",
  dns: ["1.1.1.1", "8.8.8.8"],
  port: 51820,
})
```

Options include `port`, `ip`/`address`, `interface`, `dns`, `postUp`, `postDown`, `mtu`, `table`, and `peers`.

## Client API

### `generateClientConfig(options)`

Creates a standalone client configuration.

```ts
const text = generateClientConfig({
  privateKey: clientPrivateKey,
  clientAddress: "10.0.0.2/32",
  serverPublicKey: serverPublicKey,
  serverEndpoint: "vpn.example.com:51820",
  allowedIPs: ["0.0.0.0/0", "::/0"],
  dns: "1.1.1.1",
  persistentKeepalive: 25,
})
```

### `generateClientQRCode(config, options?)`

Accepts config text, a `WireGuardConfig`, or `GenerateClientConfigOptions`.

- Default result: PNG data URL
- `type: "terminal"`: ANSI terminal QR code
- `outputPath`: writes a PNG file

## Interface API

### `up(iface, options?)` / `down(iface)`

Start or stop an interface without invoking a shell. Windows uses the WireGuard tunnel service.

### `restart(iface, options?)`

Stops and starts an interface.

### `isWgUp(iface)`

Returns whether `wg show <iface>` succeeds.

### `getInterfaceStatus(iface)`

Parses stable `wg show <iface> dump` output into interface and peer statistics.

### `getLatestHandshake(iface)`

Returns peer handshake timestamps, endpoints, transfer counters, formatted transfer text, and keepalive values.

### `syncConf(iface)`

Applies `wg-quick strip <iface>` through a secure temporary file and `wg syncconf`.

### `saveConfig(iface, options?)`

Saves the running interface configuration or returns/writes `wg showconf` output.

## Installation and Checks

### `checkWg()` / `requireWg()`

Check for the `wg` executable or throw a descriptive error.

### `installWg(options?)` / `getInstallInstructions()`

Detect the platform/package manager and install WireGuard using argument-array commands without shell interpolation.

## Errors

All errors extend `WireGuardError`:

- `ConfigParseError`
- `ConfigValidationError`
- `WgNotFoundError`
- `CommandError`
- `PeerNotFoundError`
- `PeerAlreadyExistsError`
- `AddressPoolExhaustedError`
- `UnsupportedPlatformError`

- `WG_UTILS_WG_QUICK_PATH`
- `WG_UTILS_WIREGUARD_PATH`
