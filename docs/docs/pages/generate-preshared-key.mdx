# generatePresharedKey

Generate a WireGuard preshared key with `wg genpsk`.

## Signature

```ts
generatePresharedKey(options?: {
  keyPath?: string
}): Promise<{
  presharedkey: string
  keyPath?: string
}>
```

## Basic usage

```ts
import { generatePresharedKey } from "@kriper0nind/wg-utils"

const { presharedkey } = await generatePresharedKey()
```

No file is written unless `keyPath` is provided.

## Write the key to a file

```ts
const result = await generatePresharedKey({
  keyPath: "/etc/wireguard/clients/client1.psk",
})

console.log(result.presharedkey)
console.log(result.keyPath)
```

The parent directory is created when necessary and the file is written with mode `0600`.

## Add a peer with a PSK

```ts
import { addPeer, generateKeys, generatePresharedKey } from "@kriper0nind/wg-utils"

const clientKeys = await generateKeys()
const { presharedkey } = await generatePresharedKey()

await addPeer("/etc/wireguard/wg0.conf", {
  publicKey: clientKeys.publicKey,
  presharedKey: presharedkey,
})
```

Include the same PSK in the client configuration:

```ts
import {
  addPeer,
  generateClientConfig,
  generateKeys,
  generatePresharedKey,
  getPubKey,
} from "@kriper0nind/wg-utils"

const clientKeys = await generateKeys()
const { presharedkey } = await generatePresharedKey()

const peer = await addPeer("/etc/wireguard/wg0.conf", {
  publicKey: clientKeys.publicKey,
  presharedKey: presharedkey,
})

const { publicKey: serverPublicKey } = await getPubKey("/etc/wireguard/wg0.conf")

const clientConfig = generateClientConfig({
  privateKey: clientKeys.privateKey,
  clientAddress: peer.address,
  serverPublicKey,
  serverEndpoint: "vpn.example.com:51820",
  presharedKey: presharedkey,
})
```

## Security

- Treat PSKs like private keys.
- Do not commit or log generated PSKs.
- Rotate the PSK when rotating the matching client key pair.
